Use Inter for interface text. Use JetBrains Mono for code and values where character identity or alignment matters, such as an invoice number, SKU, or job identifier.

## Type roles

| Role                         | Size            | Weight  |
| ---------------------------- | --------------- | ------- |
| Metadata and captions        | 12px            | 400–500 |
| Table headers                | 12px            | 600     |
| Product body and table cells | 14px            | 400     |
| Controls and labels          | 12–16px by size | 500     |
| Product section titles       | 16–18px         | 600     |
| Product page titles          | 20–24px         | 600     |
| Important operational values | 20–28px         | 500–600 |
| Documentation prose          | 15–16px         | 400     |

Choose the reading profile for guides and long explanations. Keep product workflows at the compact operational baseline. Use sentence case for labels; preserve uppercase in identifiers that require it.

## Spacing

Use the 4px rhythm. Common intervals are 4, 8, 12, and 16px. Use 20px for focused setup and larger gaps when the composition needs separation.

Treat control density, information density, and page composition as separate decisions. A broad data table can contain compact controls. A focused form can have breathing room around the same compact controls.

## Control sizes

The control vocabulary is `xs`, `sm`, `md`, `lg`, and `xl`. Size coordinates height, padding, text, line height, radius, icon dimensions, and gaps. Use the live controls and recipe in a component guide to inspect its scale.

The primary Button defaults to `sm`. Overlay width and the sidebar's numeric width are different APIs; they do not inherit a control height.

## Geometry profiles

With the default 10px radius token and a 16px browser root, use these control measurements:

| Size | Control height | Control radius | Group or sized surface radius |
| ---- | -------------- | -------------- | ----------------------------- |
| xs   | 24px           | 5px            | 9px                           |
| sm   | 28px           | 6px            | 10px                          |
| md   | 32px           | 8px            | 12px                          |
| lg   | 36px           | 10px           | 14px                          |
| xl   | 40px           | 12px           | 16px                          |

Button, Input, Select, and their related field controls share the control profile. Tabs and Toggle Group use that profile for their items, with 4px inset padding and an outer radius 4px larger. Match the sliding tab indicator to the tab's radius. Toolbars and calendar containers follow the group radius. Hints and notifications use the sized surface radius while their text and padding follow size.

Cards, tables, menus, popovers, documentation previews, and code blocks use `rounded-lg`, or 10px with the default token. Dialogs use `rounded-xl`, or 14px. Overlay width changes the available space; it does not change the surface radius.

Use fully round geometry for avatars, radio indicators, step markers, tracks, and knobs. An explicit icon or consumer shape override can use a different radius. The line tab variant uses square corners for its underline. Keep ordinary panels and fields planar.

## Icons and exact data

Use Tabler for structural icons, Feather where a fallback is needed, and Simple Icons for brand marks. Give icons distinct meanings and keep one family within a visual group. Ordinary control icons are around 16px and follow their component's size recipe.

Align quantities and amounts for comparison. Use monospace only where it helps read the value. Keep totals, destructive impact counts, and quantities visible; offer a way to recover truncated labels.

## Touch targets

Provide at least a 44px effective target for frequent actions on coarse pointers. Choose that behavior by pointer modality as well as viewport width. A large tablet can still require touch spacing. For a small checkbox or switch, expand the hit area around its compact visual instead of stretching the indicator or track. Keep adjacent targets from overlapping.

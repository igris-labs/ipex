Use motion to acknowledge an action, show where a surface came from, or preserve continuity during a layout change. Keep repeated product interactions immediate.

## Timing

Use these canonical timings when adding or changing interactions:

| Interaction                           | Duration                |
| ------------------------------------- | ----------------------- |
| Press response                        | 100ms                   |
| Hover, focus, checkbox, radio, switch | 150ms                   |
| Selected mode indicator               | 180ms                   |
| Menu or popover                       | 160ms enter, 120ms exit |
| Tooltip enter                         | 120ms                   |
| Dialog                                | 200ms enter, 160ms exit |
| Drawer or layout change               | 240ms                   |
| Focused page entry                    | 180ms                   |

Use the shared interaction, enter, exit, layout, and emphasis easing roles. Interaction uses ease-out cubic; entry uses ease-out quart; exit uses ease-in cubic; layout uses ease-in-out cubic. Use the emphasis curve when the action needs extra attention.

Prefer opacity, transform, and short color transitions. Interpolate shadows on tactile or elevated surfaces where they communicate depth. Animate height when a disclosure needs it and clipping remains controlled.

Keep bounce, elastic overshoot, long entrances, and decorative motion out of routine controls. Respect reduced-motion preferences while retaining immediate state changes.

## Keyboard and focus

Provide visible focus and preserve the primitive's keyboard behavior. Keep modal focus inside the open dialog and return it to the trigger on dismissal. Support keyboard alternatives to drag and drop, and place focus in a useful region after navigation.

Use semantic controls with accessible labels. Give icon-only buttons a name. Keep tooltips as supplementary descriptions rather than the only explanation of an action.

## Readability and feedback

Meet WCAG AA for normal text. Evaluate the boundaries that identify controls without darkening every passive separator. Pair color with text, an icon, or a state indicator.

Associate labels, descriptions, and errors with their inputs. Announce errors and asynchronous results where the person needs that feedback. Toasts should report outcomes without stealing focus.

## Input methods

Check mouse, keyboard, touch, and coarse-pointer behavior. Keep frequent touch targets at least 44px. Respect safe areas around fixed actions and test text enlargement, long labels, and loading geometry.

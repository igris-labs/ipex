IPEX means **Igris Platform EXperience**. It gives applications built under Igris Labs a shared visual language and interaction model.

The system covers page widths, information density, typography, color, controls, motion, and accessibility. Use it to build data-heavy tools, editors, settings, forms, and other product interfaces.

## The experience

Keep the structure neutral so people can scan their work. Give selected controls, primary actions, and feedback enough emphasis to recognize them.

| Area          | Approach                                                                                      |
| ------------- | --------------------------------------------------------------------------------------------- |
| Layout        | Use available width for data. Keep forms and focused tasks within a bounded workspace.        |
| Density       | Use compact controls with consistent text, padding, icons, and corners.                       |
| Color         | Keep primary and secondary neutral. Use accent for emphasis and semantic colors for feedback. |
| Material      | Give primary actions a tactile surface. Keep fields, tables, and surrounding structure flat.  |
| Motion        | Use short transitions to connect states. Respect reduced-motion preferences.                  |
| Accessibility | Preserve keyboard navigation, visible focus, labels, and disabled states.                     |

## Components

IPEX components use Vue 3, Akaza UI, Tailwind CSS, and Tailwind Variants. Akaza provides behavior and accessibility. IPEX adds styling, size profiles, and shared defaults.

You copy the source into your application. Each component has a folder containing its Vue implementation and an `index.ts` with its recipe, types, configuration, and exports. You can edit those files to suit your application.

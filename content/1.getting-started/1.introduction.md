IPEX means **Igris Platform EXperience**. It is the shared design system for applications built under Igris Labs, a personal lab that brings its projects under one umbrella.

IPEX defines how those applications look and behave: page widths, information density, typography, color, control materials, motion, and accessibility. Use it for operational tools, builders, administration, settings, authentication, and documentation. The system grew from production work in Iomniq.

## The experience

When you scan a table, compare the records across the available width. When you configure a rule, keep the editor and its preview near each other. When you commit a change, the primary action should feel distinct from the surrounding tools.

These choices are part of IPEX. A consistent experience depends on the composition around a component as well as the component itself.

| Principle           | In the interface                                                                       |
| ------------------- | -------------------------------------------------------------------------------------- |
| Calm at rest        | Neutral surfaces, compact controls, fine boundaries, and stable alignment.             |
| Expressive in state | Clear selection, visible focus, useful drag feedback, and explicit outcomes.           |
| Tactile in control  | Layered material and directional edge lighting on execution actions and engaged modes. |
| Fluid in motion     | Immediate feedback and short transitions that preserve context.                        |
| Focused in space    | Wide data views, bounded workbenches, and narrower forms and settings.                 |

At rest, keep most visual weight in the quiet structure. Reserve stronger treatment for execution, selection, feedback, and overlays. An active mode or a blocking error still needs enough emphasis to recognize it.

## A Vue implementation you own

The component library implements IPEX with Akaza UI for behavior, Tailwind CSS for styling, and Tailwind Variants for recipes. Copy the components into your application and edit their source. Use shared CSS tokens for the theme and `ui.config.ts` for compatible component defaults.

The catalog includes inputs, selection controls, navigation, calendars, data tables, overlays, and layout components. Each guide includes a live preview, the supported options, its API, and the source used by the preview.

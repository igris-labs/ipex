## Requirements

Use Node.js 22.19 or newer, Vue 3.5 or newer, and Tailwind CSS 4. Start with a Vue or Nuxt application.

## Packages

Install the shared runtime dependencies and Tailwind build tools:

```sh
pnpm add akaza-ui tailwind-variants cn
pnpm add -D tailwindcss @tailwindcss/vite
```

Use Tailwind Variants' lite entry for recipes. Use `cn` for class merging. You do not need `tailwind-merge`, CVA, or Nuxt UI.

## Nuxt setup

Install the font and color-mode modules if your application does not have them:

```sh
pnpm add @nuxt/fonts @nuxtjs/color-mode
```

Register Akaza, fonts, and color mode. Add Tailwind's Vite plugin and your shared CSS entry:

```ts [nuxt.config.ts]
import tailwindcss from '@tailwindcss/vite'

export default defineNuxtConfig({
  modules: ['akaza-ui/nuxt', '@nuxt/fonts', '@nuxtjs/color-mode'],
  css: ['~/assets/main.css'],
  colorMode: { classSuffix: '', preference: 'system', fallback: 'light' },
  vite: { plugins: [tailwindcss()] },
})
```

Akaza's Nuxt module loads its structural stylesheet. Nuxt Fonts loads the Inter and JetBrains Mono families declared in the theme. The color-mode module applies `.light` or `.dark` to the document; use `useColorMode()` to change the preference.

## Vue with Vite

Keep your Vue plugin and add Tailwind to your Vite plugins:

```ts [vite.config.ts]
import tailwindcss from '@tailwindcss/vite'
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [vue(), tailwindcss()],
})
```

Load Inter and JetBrains Mono through your font provider. To use local font packages:

```sh
pnpm add @fontsource/inter @fontsource/jetbrains-mono
```

Use these imports at the beginning of the theme file below. Reserve Akaza's reset layer first, then load its structural CSS after Tailwind:

```css [src/assets/main.css]
@layer akaza-reset;
@import '@fontsource/inter/latin-400.css';
@import '@fontsource/inter/latin-500.css';
@import '@fontsource/inter/latin-600.css';
@import '@fontsource/jetbrains-mono/latin-400.css';
@import 'tailwindcss';
@import 'akaza-ui/dist/akaza-ui.css';
```

Import your CSS entry once from `src/main.ts`. Apply `.dark` to the document element to select the dark theme. Nuxt Color Mode is optional for standalone Vue applications.

## Add a component

Start with [Button](/components/button). Copy its `Button.vue` and `index.ts` into `app/components/ui/button`. For Vue with Vite, replace the `app` directory with `src` while keeping the relative file structure.

```vue
<script setup lang="ts">
import { Button } from '~/components/ui/button'
</script>

<template>
  <Button>Create project</Button>
</template>
```

Use your project's path alias or a relative import in standalone Vue. Shared setup belongs on this page; component pages contain the files and examples for that component. Installation currently uses manual copying.

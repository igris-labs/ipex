## Import a component

After [installation](/getting-started/installation), import from the component's local folder:

```vue [app/components/ProjectAction.vue]
<script setup lang="ts">
import { ref } from 'vue'
import { Button } from '~/components/ui/button'

const saved = ref(false)
</script>

<template>
  <Button @click="saved = true">Save project</Button>
  <p v-if="saved" role="status">Project saved.</p>
</template>
```

Use your application's alias or a relative import in a Vue with Vite project.

## Defaults

Set shared defaults in `app/components/ui/ui.config.ts`. A component uses only the global values it supports.

```ts [app/components/ui/ui.config.ts]
import type { UiConfig } from './ui.types'

const uiConfig: UiConfig = {
  defaults: { size: 'md' },
  components: {
    button: { color: 'primary', variant: 'solid' },
    input: { variant: 'outline' },
  },
}

export default uiConfig
```

An explicit prop takes priority over the component setting, then a compatible global default, then the component's built-in default. Omitted or `null` variant props inherit the next setting.

## Props and state

Choose size, color, and variant independently when a component supports them. Use `v-model` for controlled values and named slots to replace content.

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Button } from '~/components/ui/button'
import { Input } from '~/components/ui/input'

const projectName = ref('')
</script>

<template>
  <Input v-model="projectName" aria-label="Project name" />
  <Button color="secondary" variant="soft" size="md">Review changes</Button>
</template>
```

Each component's API lists its models, props, slots, events, and exposed methods. Cancelable change events provide `details.cancel()` to prevent an update.

## Accessibility

Give inputs visible labels through Field or an accessible name through `aria-label`. Give icon-only buttons an accessible name. Preserve keyboard focus when customizing classes or replacing slots.

```vue
<Button shape="icon" aria-label="Close panel">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" aria-hidden="true">
    <path d="m6 6 12 12M6 18 18 6" />
  </svg>
</Button>
```

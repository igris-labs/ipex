## Global defaults

Edit `ui.config.ts` to change shared defaults:

```ts
import type { UiConfig } from './ui.types'

const uiConfig: UiConfig = {
  defaults: { size: 'md' },
  components: {
    button: { color: 'primary', variant: 'solid' },
  },
}

export default uiConfig
```

## Resolution order

An explicit prop overrides the component setting. The component setting overrides a compatible global default. The component recipe supplies the fallback.

For Button, the fallback is primary, solid, small, and the default shape. `null` and omitted values both inherit the next available setting. Button ignores an unsupported global variant, such as a primitive's `default` variant.

## Separate axes

Choose color, variant, and size independently:

```vue
<Button color="secondary" variant="outline" size="lg">Review changes</Button>
```

Use `shape="icon"` for a square button and supply an accessible label. Keep the size prop as `xs`, `sm`, `md`, `lg`, or `xl`.

## Exploring component previews

Use the size and variant selectors above a preview to inspect its geometry and appearance. **Options and states** exposes scalar props such as disabled, read-only, invalid, loading, selection mode, placement, and labels when the component supports them. **Default** leaves the prop unset so the component or your shared UI configuration supplies it.

The API tables cover data structures, callbacks, models, and slots. Focused demos show patterns that need composition: table filtering and selection, form groups, avatar fallbacks, and application layouts. Button uses the same configurable preview and adds visual comparisons for colors, variants, and sizes.
